# Комплекты из архивов 0001–0003

Обновите программу и повторно запустите установщик профилей:

```powershell
.\venv\Scripts\python.exe -m scripts.install_customer_templates
```

Установщик добавляет бланки в существующий справочник без замены уже
назначенных форм. Бланки сохраняются как черновики для проверки.

## ЗВКС, извещение 32616469080

Источник Word — приложение № 4, извещение с отметкой «версия 2».
В закупке предусмотрены две отдельные части.

| Часть | Бланки программы |
|---|---|
| Первая | Форма 2 «Предложение об условиях исполнения договора». Программа берёт предмет и описание по ТЗ. Реквизиты участника, подпись, сведения о квалификации и цена автоматически не подставляются. |
| Вторая | Форма 1 «Заявка», форма 3 «Сведения об участнике» и форма 5 «Опись». В них подставляются доступные реквизиты и сведения о подписанте. |

Собирайте части в разные папки и перед подачей проверяйте вложения в каждой.
Форма 4 предназначена для участника-физлица. Кроме того, в полученном
бланке адресат и лицо, которому даётся согласие, указаны по-разному.
Для такой заявки нужно получить или проверить актуальный бланк у заказчика.
Подтверждения второй части проверяйте по пункту 9.2 извещения.
Для заполнения характеристик первой части используйте актуальные ТЗ и
календарный план. В списке Windows они указаны как
`1. ТЗ_корректировка КЭР ЗВКС (версия 2).doc` и
`2. Календарный план 14.10.2026 (версия 2).docx`.

## АО «Инфраструктурные проекты», извещение 32414064111

| Номер | Бланк и способ заполнения |
|---|---|
| 1 | Опись. Участник и предмет из карточки, перечень и страницы по фактическим вложениям. Форма рекомендательная. |
| 2 | Оферта. Реквизиты, предмет и суммы из позиций лота. Подтверждение условий и роль указываются явно. Аккредитационный вариант и одобрение сделки сверяются вручную. |
| 3 | Коммерческое предложение. Позиции и суммы из карточки. Единицы, количество, цена единицы и официальная книга НМЦ проверяются отдельно. |
| 4 | Техническое предложение. Описание по ТЗ вводится на карточке тендера. |
| 5 | График. Начало и окончание из ответов. Этапы уточняются по ТЗ. |
| 6 | Анкета. Подставляются доступные реквизиты компании. |
| 7 | Опыт. Подставляются только отобранные договоры. Сведения об объёмах и годовую сводку сверяют с подтверждениями. |
| 8 | МТР. Подставляются только отобранные ресурсы. |
| 9 | Кадры. Подставляются только отобранные сотрудники. |
| 10 | Аффилированность. Печатаются введённые сведения после явного подтверждения. |

Пункт о составе заявки и таблица приложения № 4 требуют формы 2–6.
Формы 7–10 используются по применимым требованиям. Аккредитационная книга
из приложения № 9 и обязательная к ценовой части книга структуры НМЦ
остаются в исходном формате. Встроенный образец структуры содержит строки
«Продукция 1» и другие учебные значения. Нужна отдельная книга лота,
`3.Структура_НМЦ_-1470.xlsx`, указанная в выгрузке архива Windows.

## Остальные материалы в первых трёх ZIP

- По ННГ пришли уже использованные формы и методики, а также документы
  поданной заявки. Заполненные и подписанные файлы хранятся отдельно от
  шаблонов.
- По Донскому ГВРЦ (0358200011825000004) есть приложение № 4 с требованиями
  по 44-ФЗ. Оно используется для сверки состава заявки на площадке.
  Отдельный готовый Word-бланк заявки в приложении не выделен.
- По Горномарийской, Параньгинской и Юринской СББЖ есть извещения.
  Требования и инструкция находятся в отдельных приложениях № 4,
  которых нет в первых трёх ZIP.
- По Госветинспекции Пермского края есть извещения 0356500001425002119 и
  0356500001425002120. В выгрузке отдельно указаны файлы «Требования к
  составу и содержанию заявки.docx» и «Критерии оценки.docx».

Бухгалтерские документы, подписанные формы, персональные данные и сканы
из архивов не включены в программу. Для подачи используйте актуальные
документы и редакцию извещения.
